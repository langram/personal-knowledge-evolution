# 英文改写与术语说明

English title: **New Principles: Modern Science and the Making of Human Civilization**.

英文全文以本版中文为唯一基准，保留独立作品的叙述方式；采用英语习惯组织句子，不加入读者必须了解旧稿的回顾。31 章全部阅读并改写，章节层级和外部链接逐项核对。原话在来源层保持中文原文；英文是明确标注的派生版本，不冒充新的作者原生发言。

## 核心术语

| 中文 | English | 用法 |
|---|---|---|
| 新原理 | New Principles | 书名 |
| 公平的发展条件 | fair conditions for development | 不等同于相同能力结果 |
| 能力互补 | complementary abilities / complementarity | 保留不同能力结构 |
| 跨领域合作 | cooperation across fields / disciplines | 根据语境自然表达 |
| 动态权重 | dynamic decision weights | 区分任务相关影响力与执行权 |
| 公共知识 | public/shared knowledge; common knowledge | 共享资料与博弈中的相互知晓按语境区分 |
| 数据主权 | data sovereignty | 具体控制、迁移和退出能力 |
| 按需保障 | provision according to need | 与共同生产资源的治理区分 |
| 对偶体 | Dualoid | 尚待形式化的作者概念 |
| 不动点 | fixed point | 不自动包含收敛性 |
| 自我实现的科幻 | self-realizing science fiction | 通过自愿创作与实践连接想象和现实 |
| Merkle-DAG / FPM / Structoken / MerkleVM / HotPath | 原名保留 | 不将不同项目合并成已实现的统一产品 |
